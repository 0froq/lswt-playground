# Welcome to LSWT Playground

This platform provides interactive tools for analyzing **Lake Surface Water Temperature (LSWT)** data with advanced statistical methods and visualization.

## What You Can Do

### 🔬 Mutation Detection
Detect significant change points in lake temperature time series using:
- **Pettitt Test** - Non-parametric test for detecting a single change point
- **Sequential T-Test** - Multiple change point detection
- **Statistical Metrics** - OLS regression, Sen's slope estimator, variance analysis

### 📊 Segmentation Analysis
Compare lake temperature across different time periods:
- Define custom break years
- Statistical comparison between segments
- Visualize differences with interactive charts

### 📈 Interactive Visualization
All analyses feature rich, interactive Plotly visualizations with:
- Dark/light mode support
- Zoom and pan capabilities
- Hover tooltips with detailed information
- Responsive design
