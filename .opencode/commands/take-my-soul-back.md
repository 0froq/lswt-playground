# Take My Soul Back

Review or delete soul memory - gives user full control.

## What this does

1. Show current soul.md content
2. Offer options:
   - View memory (read-only)
   - Export memory
   - Delete specific sections
   - Delete all soul memory (reset)

## Safety

- Always confirm before deletion
- Offer to export before deleting
- Explain what will be lost

## Output format

```
=== Your Soul Memory ===
[Content]

Options:
1. Export (save to file)
2. Delete section [X]
3. Delete all (reset)
4. Cancel

Choose:
```

This command ensures the user always has ownership and control.
