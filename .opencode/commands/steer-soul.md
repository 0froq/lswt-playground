# Steer Soul

Update the persistent soul memory with new goals, preferences, or context.

## What this does

1. Read current soul.md
2. Ask user what they want to update:
   - New goals to add
   - Preferences to change
   - Context to add
   - Patterns to note
3. Update soul.md with the new information
4. Confirm the changes

## Example prompts

- "Add goal: migrate to Vue 3"
- "Note: user prefers dark mode"
- "Add context: working on authentication feature"

This is how you teach Soul about your evolving needs.
